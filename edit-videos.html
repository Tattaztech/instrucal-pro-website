Gérer les vidéos

Ajoutez une vidéo, modifiez son texte ou choisissez les modules où elle apparaît.

  1. Pour une nouvelle vidéo, déposez le MP4 et, si vous en avez une, sa vignette WebP dans le dossier des vidéos sur GitHub.
  2. Renseignez le formulaire, puis téléchargez votre fichier videos.json.
  3. Déposez ce fichier sur GitHub avec son nom exact, videos.json, puis validez le commit sur main. GitHub Pages actualisera le site.
