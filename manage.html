Gérer mon site

Modifiez l’accueil de TATAZ TECH LLC, la présentation d’InstruCal Pro, les photos et les vidéos depuis Pages CMS.

  1. Connectez-vous avec le compte GitHub propriétaire du dépôt.
  2. Lors de la première connexion, autorisez Pages CMS sur le seul dépôt instrucal-pro-website.
  3. Ouvrez TATAZ TECH LLC — accueil et catalogue, InstruCal Pro — accueil et thème ou Vidéos, puis enregistrez vos modifications. Les changements enregistrés sur main deviennent publics après le déploiement GitHub Pages.
